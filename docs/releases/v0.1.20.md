# QBRemote 0.1.20（21）更新说明

## 中文

- 适配 Android 16（API 36）并完善无边框、刘海和键盘边衬处理。
- 修复全局限速读取、服务器无感切换、独立草稿及保存回读校验。
- 修复卡片长按重排时的残影/闪烁，并提升主题快速切换的持久化稳定性。
- 国家热力图改为“今日唯一 Peer 连接数”，删除“存储压力”卡片。
- 优化新增/编辑服务器表单，键盘弹出后所有输入项仍可滚动到可见区域。

## English

- Updated for Android 16 (API 36) with improved edge-to-edge, cutout, and IME inset handling.
- Fixed global speed-limit loading, seamless server switching, per-server drafts, and save read-back verification.
- Fixed card reorder ghosting/flicker and made rapid theme changes persist reliably.
- Changed the country heat map to today’s unique observed peer count and removed the Storage Pressure card.
- Improved the add/edit server form so every field remains reachable while the keyboard is open.
